# Voyage Atlas 디자인 가이드 (DESIGN.md)

> 이 문서는 Claude Code가 나의 여정 지도(Voyage Atlas)를 구현할 때 따르는 시각 디자인 명세입니다.
> 기능 명세는 `../docs/Voyage_Atlas_PRD.md`(PRD v0.3)를 따르고, 이 문서는 **어떻게 보이고 느껴져야 하는지**를 정합니다. PRD 6장과 이 문서가 다르면 이 문서를 우선합니다.
> 화면 시안: `design-mockup.html` (인터넷 연결 없이도 열리며, 상단 탭으로 10개 화면을 오갈 수 있습니다)

## 1. 콘셉트: Midnight Atlas & Gold Foil

**밤하늘 위의 금박 스크래치 지도.**
아직 가지 않은 땅은 금박으로 덮여 있고, 다녀온 곳은 금박이 긁혀 나가며 오로라 빛이 드러납니다. 가고 싶은 곳은 지도 위에서 반짝이는 별입니다.

| 모티프 | 앱에서의 쓰임 | 전달하는 감정 |
|---|---|---|
| 금박(골드 포일) | 미방문 국가·시도, 주요 버튼, 배지 코인 | 긁어 보고 싶은 기대 |
| 금박 긁기 | 방문 표시 순간의 연출 | 성취감 |
| 오로라 4단계 | 방문 횟수(1·2·3·4회 이상) | 쌓여 가는 추억 |
| 별(4각 반짝임) | 위시리스트, AI 추천(합의) | 희망, 설렘 |
| 비행 궤적(대권 곡선) | 여행 경로, 지구본의 출발 궤적 | 여정의 서사 |
| 금화(코인) | 마일스톤 배지 | 자부심 |
| 밤하늘과 성운 | 배경 | 넓은 세계, 꿈 |

### 디자인 원칙
1. **지도가 주인공.** 지도 화면은 전체 화면을 지도에 주고, 나머지 UI는 반투명 유리 패널(`.glass`)로 띄웁니다. 화면을 옮겨도 지도는 사라지지 않게 합니다.
2. **금색은 '보상과 행동'에만.** 금색 그라데이션은 주요 버튼, 핵심 숫자, 획득 배지, 현재 탭에만 씁니다. 장식용으로 흩뿌리지 않습니다.
3. **색칠은 오로라, 미방문은 금박.** 지도 위에서 두 질감이 명확히 대비되어야 합니다. 방문한 곳에는 금박 질감을 쓰지 않습니다.
4. **숫자는 크게, 자랑스럽게.** 방문국 수, 여행 일수 같은 핵심 숫자는 Fraunces 800으로 크게, 바뀔 때는 카운트업합니다.
5. **클릭마다 보상, 하지만 짧게.** 색칠 연출은 1초 이내입니다. 빠른 색칠 모드와 "애니메이션 줄이기"에서는 더 짧게 줄입니다.
6. **색만으로 구분하지 않기.** 방문 단계는 범례 숫자로, 위시는 별 모양과 점선 테두리로, 경유는 빗금 패턴으로, AI 모델은 2글자 모노그램(CL/GP/GM)으로 함께 구분합니다.

>
> **시안 확정(v0.3)**: 이 시안을 최종 디자인으로 확정했습니다. 실제 앱은 가능한 한 시안의 모습과 연출을 그대로 따릅니다. 시안과 다른 점은 ① 국기 이미지(12장), ② '거주' 상태 없음, ③ 한국 시도 코드(행정표준코드) 정도입니다.

## 3. 디자인 토큰

아래 CSS 변수를 `css/tokens.css`의 `:root`에 넣고, 컴포넌트에서는 HEX 대신 변수를 씁니다. 다크(밤하늘)가 기본이고, 라이트(빈티지 지도)는 `:root[data-theme="light"]`로 덮어씁니다.

### 색 사용 규칙
| 색 | 써도 되는 곳 | 쓰지 않는 곳 |
|---|---|---|
| `--gold` 계열 | 주요 버튼, 핵심 숫자, 현재 탭, 획득 배지, eyebrow 라벨 | 본문 글자, 넓은 면 배경 |
| `--foil-*` | 미방문 땅, 금박 범례 | 버튼, 카드 배경 |
| `--v1~v4` | 방문 단계 채색, 진행 막대 그라데이션, 차트 | 글자색(대비 부족) |
| `--wish` | 위시 별, D-day 숫자, 위시 태그 | 일반 강조 |
| 모델 색 | AI 모델 점·핀·모노그램 | 그 밖의 모든 곳 |
| 대륙 색(차트 전용) | 아시아 `#2EC4B6`, 유럽 `#9B5DE5`, 북아메리카 `#4C8DFF`, 오세아니아 `#F15BB5`, 아프리카 `#FFB347`, 남아메리카 `#7BD389` | 지도 채색(지도는 방문 횟수 기준) |

- 배경은 `--bg` 위에 성운 두 개(`radial-gradient`)와 별 캔버스(약 220개, 15%는 금빛)를 고정으로 깝니다. 라이트 테마에서는 별 캔버스를 숨깁니다.
- 금박 질감은 `--foil-*` 그라데이션에 미세 노이즈 필터(`#grain`)를 지도 땅 그룹 전체에 한 번만 겁니다(나라마다 걸지 않음).

## 4. 타이포그래피

| 역할 | 글꼴 | 크기 / 굵기 | 예 |
|---|---|---|---|
| Display(화면 제목) | Fraunces + Noto Serif KR | `clamp(28px, 4vw, 44px)` / 700, 자간 -0.02em | "아직 닿지 않은 별 6개" |
| Number(핵심 숫자) | Fraunces | 56~76px / 800, `tabular-nums lining-nums`, 자간 -0.03em | 19, 214, D-98 |
| Title(카드 제목) | Pretendard | 18px / 700 | "가장 많이 간 나라" |
| Body | Pretendard | 14~15px / 400, 줄 간격 1.55 | 추천 이유 |
| Label/Eyebrow | JetBrains Mono | 11px, 대문자, 자간 0.18em, `--gold` | MY VOYAGE · 2016 — 2026 |
| 수치 보조 | JetBrains Mono | 11~12px | 8/48, $0.031 |

- Fraunces에는 한글이 없어 한글 글자는 자동으로 Noto Serif KR로 표시됩니다. 이 조합이 "지도책 같은 고전미"의 핵심이므로 순서를 바꾸지 않습니다.
- 본문 한글 줄바꿈은 `word-break: keep-all`.
- 글꼴 불러오기: Google Fonts(Fraunces, Noto Serif KR, JetBrains Mono) + Pretendard(jsDelivr, 고정 버전 `v1.3.9`). PWA에서는 서비스 워커로 캐시합니다.
- 공유 이미지에서는 글꼴이 SVG→이미지 변환 시 빠질 수 있으므로 실제 앱은 글자를 Canvas `fillText`로 직접 그립니다(PRD 10.4절).

## 5. 레이아웃

### 5.1 지도 화면(지도 홈, 대한민국, 지구본, AI 추천)
```
┌──────────────────────────────────────────────────────────────┐
│ [HUD 통계 300px]     [보기 전환 · 검색]          [가장 가까운 꿈] │
│                                                    [빠른 색칠 안내]│
│                      ( 전체 화면 지도 )                          │
│                                                                │
│ [범례]                  [하단 탭 바]                  [＋][－][⤢] │
└──────────────────────────────────────────────────────────────┘
```
- 지도 무대 높이: `calc(100vh - 상단바)`, 최소 680px.
- 떠 있는 패널은 가장자리에서 20px, 서로 겹치지 않게 배치합니다.
- AI 추천 화면은 오른쪽 360px 패널에 추천 목록을 두고, 지도는 그 왼쪽 영역에만 그립니다.

### 5.2 일반 화면(통계, 연대기, 위시, 공유)
- 본문 최대 너비 1280px(공유 스튜디오 1400px), 좌우 여백 24px, 섹션 간격 24px.
- 상단: eyebrow → Display 제목(2줄 허용) → 오른쪽에 보조·주요 버튼.
- 카드 그리드: `repeat(auto-fit, minmax(min(100%, 420px), 1fr))`.

### 5.3 반응형
| 너비 | 변화 |
|---|---|
| ≤ 980px | 오른쪽 "가장 가까운 꿈"·안내 패널 숨김, HUD 260px, 공유 스튜디오 1열 |
| ≤ 860px | 연대기 2열 → 1열 |
| ≤ 720px(모바일) | 지도 무대가 세로 흐름으로 바뀜: 상단 보기 전환·검색(전체 너비) → 지도(62vh) → HUD 카드 → 범례. 확대 버튼·데스크톱 탭 바 숨김, 모바일 탭 바 사용 |

### 5.4 모바일 앱 셸(09 시안)
- 지도 전체 화면 + 상단 검색 알약 + **하단 시트 3단계**(접힘 120px / 절반 / 전체) + 하단 탭 바(지도·연대기·위시·AI·통계, 높이 64px, 가장자리 12px 띄움).
- 장소를 누르면 시트가 장소 상세로 바뀝니다(국기, 방문 횟수, 도시 칩, [위시] [＋ 방문 기록]).
- 터치 영역 최소 44×44px.

## 6. 컴포넌트 명세

### 6.1 Glass 패널 (`.glass`)
- 배경 `--panel`, 테두리 1px `--line`, 반경 24px, `backdrop-filter: blur(18px) saturate(140%)`, 그림자 `--shadow`.
- 지도 위에 뜨는 모든 패널, 팝오버, 토스트, 모달에 사용.

### 6.2 버튼
| 종류 | 모양 | 용도 |
|---|---|---|
| Primary | 금박 그라데이션(`--gold-strong → --gold → --gold-deep`), 글자 `--on-gold`, 안쪽 위 하이라이트 + 금빛 그림자 | 화면당 1~2개: 긁어서 방문 표시, 추천 실행, PNG 저장 |
| Secondary | `--panel-2` 배경, `--line` 테두리 | 위시 담기, 기록 추가, 편집 |
| Ghost | 투명 | 취소 |
| Icon | 44×44 원형 Glass | 확대·축소 |
- 높이 44px(작은 버튼 34px), 알약 모양, 마우스를 올리면 1px 위로 이동.
- 버튼 문구 앞 기호: ✦(긁기·실행), ☆/★(위시), ＋(추가), ↻(다시), ⤓(저장), ↗(공유), ▶(재생).

### 6.3 HUD 통계 카드
- eyebrow → 큰 숫자(76px, 금박 그라데이션 글자) + 단위(개국 / 195) + **진행 링**(64px, 두께 6, 청록→분홍 그라데이션) → 다음 목표 문장(✦ ○개국만 더 가면 ○개국 달성!) → 대륙별 진행 막대 6줄(대륙 색, `방문/전체` Mono) → 보조 지표 2칸(여행 일수, 한국 시도).

### 6.4 장소 팝오버
- 너비 290px, 클릭 지점 위에 꼬리(회전한 사각형)와 함께 표시. 지도 위쪽 360px 안에서 열리면 **아래쪽으로 뒤집어** 표시합니다.
- 구성: 국기(30px) + 이름(18px 800) + `대륙 · 상태` → 한 줄 설명 → 버튼 3개(1행 Primary 전체 너비, 2행 Secondary 2개).

## 7. 지도 표현 명세

### 7.1 레이어 순서
`경위선` → `땅(국가·시도 path)` → `작은 나라 마커` → `긁기 효과(fx)` → `경로` → `핀(별·AI)` → (HTML) `파티클 캔버스` → 팝오버·툴팁.

### 7.2 상태별 채색
| 상태 | 채우기 | 테두리 |
|---|---|---|
| 미방문 | `url(#foil)` 금박 그라데이션(9초 주기로 천천히 흐르는 광택) + `#grain` 노이즈 | `--foil-edge` 0.5px |
| 미방문 + 마우스 올림 | `url(#foilHover)` 밝은 금박 | 같음 |
| 방문 1·2·3·4회 이상 | `--v1` / `--v2` / `--v3` / `--v4` | `rgba(7,11,31,.55)` 0.5px, 마우스 올리면 밝기 115% |
| 경유 | `url(#hatch)` 45° 빗금(`--transit` + `--foil-2`) | 같음 |
| 위시(국가) | 미방문 금박 유지 | `--wish` 1.4px 점선(3 3) |
- 테두리는 `vector-effect: non-scaling-stroke`로 확대해도 굵기 유지.
- 투영법: 세계 Natural Earth, 지구본 Orthographic, 한국 Mercator. 남극은 그리지 않습니다.

### 7.3 금박 긁기 연출(핵심)
1. 클릭 좌표를 중심으로 하는 원을 담은 `<mask>`를 만들고, 원에 `#rough` 필터(`feTurbulence` 0.035 + `feDisplacementMap` 38)를 걸어 가장자리를 거칠게 만듭니다.
2. 같은 나라 모양에 방문 색을 칠한 복제 path에 이 마스크를 씌우고, 원 반지름을 0 → (경계 상자에서 가장 먼 꼭짓점까지 × 1.25 + 30)으로 **850ms, easeCubicOut**으로 키웁니다.
3. 같은 마스크로 금빛 외곽선(`--gold-strong` 1.2px + 빛 번짐)을 함께 드러냈다가 500ms에 걸쳐 사라지게 합니다.
4. 클릭 지점에서 금가루 파티클 36개(금색 4톤, 1초, 중력 0.09).
5. 끝나면 원래 path의 클래스를 방문 단계로 바꾸고 마스크·복제본을 지웁니다(성능).
6. HUD 숫자 카운트업(700ms), 진행 링 갱신(800ms), 토스트 + 실행 취소.

### 7.4 시작 연출
- 첫 진입 시 방문한 나라가 70ms 간격으로 하나씩 나타납니다(300ms 지연, 각 600ms). 두 번째 진입부터는 생략.
- 지구본은 인천에서 출발하는 궤적이 90ms 간격으로 그려집니다(각 1.2초).

### 7.5 경로
- 대권 곡선(`d3.geoPath` + LineString), 선 `--gold-strong` 1.6px + 아래에 `--gold` 6px 18% 그림자 선.
- 경로 다시 보기: 구간마다 1.1초 동안 선이 그려지고 비행기 아이콘이 진행 방향으로 회전하며 따라갑니다.
- 출발지(인천)는 `--v1` 점, 방문 도시는 `--v4` 점 + 이름 라벨(라벨이 겹치면 위·아래로 번갈아 배치).

### 7.6 지구본
- 바깥 대기 광채(`#atmo`: 하늘색 → 보라, 반지름 × 1.18) → 바다(`#ocean` 방사형) → 경위선 → 땅 → 궤적 → 도시 점(금색 빛 번짐) → 위시 별.
- 뒤쪽 반구의 점·별은 숨깁니다(`geoDistance > 90°`).
- 자전 속도 0.006°/ms, 끌면 멈추고 놓으면 다시 자전. 위아래 기울기는 ±60°로 제한.

### 7.7 라벨과 툴팁
- 라벨: 11px 600, 글자색 `--text`, 바깥 테두리 3px `--bg`(`paint-order: stroke`)로 지도 위 가독성 확보.
- 툴팁: `--panel-solid` 카드, 국기 + 한국어 이름(15px) / 영어 이름 · 대륙 / 상태(금색).

## 10. 모션

## 12. 아이콘

- 아이콘 라이브러리 없이 **인라인 SVG, 선 1.6~1.8px, 둥근 끝·이음**으로 그립니다. 크기 14/16/20px, 색은 주변 글자색을 따릅니다.
- 필요한 아이콘: 지구(지도), 깃발(연대기), 4각 별(위시), 반짝임 원(AI), 막대(통계), 위 화살표 상자(공유), 돋보기, 더하기, 빼기, 전체 보기, 재생, 비행기(채움), 닫기, 체크.
- 장식 SVG는 `aria-hidden="true"`, 의미 있는 SVG(지도·차트·진행 링)는 `role="img"` + `aria-label`.
- **국기는 이모지를 쓰지 않습니다(v0.3 확정).** 윈도우에서는 국기 이모지가 "KR", "JP" 같은 글자로 보이기 때문입니다. 시안은 이모지를 썼지만 실제 앱은 다음 규칙을 따릅니다.
  - flag-icons(MIT) 4:3 SVG를 저장소 `assets/flags/<iso2>.svg`에 보관하고 `<img>`로 표시합니다(CDN 의존 없음, 오프라인·서비스 워커 캐시 대상).
  - 모양: 4:3 비율, 반경 3px, 1px `--line-2` 테두리(흰 국기도 배경과 구분되게). 크기는 툴팁 16px, 목록 20px, 팝오버 30px, 상세 56px(높이 기준).
  - 이미지가 없는 지역(예: 북키프로스, 소말릴란드)이나 불러오기 실패 시에는 **중립 깃발 아이콘**(인라인 SVG, `--text-faint`)으로 대체하고, ISO 코드 글자를 화면에 표시하지 않습니다.
  - 공유 이미지는 같은 SVG를 `Image`로 불러 Canvas에 그립니다.
  - `alt`에는 한국어 국가명을 넣습니다(예: `alt="일본 국기"`).

## 13. 접근성 체크리스트

- 글자 대비 4.5:1 이상(24px 이상 큰 글자 3:1). `--text-faint`는 12px 이상 보조 정보에만 씁니다.
- 방문 단계 색(`--v1~v4`)은 글자색으로 쓰지 않고, 범례에 숫자(1회~4회 이상)를 함께 표기합니다.
- 지도는 키보드로 조작하기 어려우므로 **검색 + 목록 보기**를 대안으로 제공하고, 목록에서도 방문 표시가 가능해야 합니다.
- 모든 상호작용은 실제 `<button>`, `<a href>`, `<input>`, `<label>`로 만들고, 세그먼트는 `aria-pressed`, 모달은 `role="dialog"` + `aria-modal`.
- 아이콘만 있는 버튼은 `aria-label`. 토스트 영역은 `aria-live="polite"`.
- 터치 영역 최소 44×44px. 작은 나라는 원형 마커로 클릭 영역을 넓힙니다.
- 포커스 표시: `--gold-strong` 2px 외곽선, 3px 띄움.

## 14. 구현 메모(Claude Code용)

1. `css/tokens.css`에 3장 토큰을 그대로 넣고, 시안의 `<style>` 2~3절(공통·컴포넌트)을 `css/app.css`로 옮겨 시작합니다.
2. 공통 SVG 정의(`#foil`, `#foilHover`, `#hatch`, `#rough`, `#glow`, `#grain`, `#starHalo`, `#ocean`, `#atmo`, `#sparkle`)는 `index.html`에 한 번만 두고 모든 지도 SVG가 참조합니다. 이 정의를 담은 SVG는 `display:none`이 아닌 크기 0으로 숨깁니다(그라데이션이 깨지지 않도록).
3. 시안 코드의 `drawWorld`, `scratch`, `particles`, `addStar`, `countTo`는 그대로 `js/map/engine.js`, `js/map/effects.js`의 출발점으로 쓸 수 있습니다.
4. 시안의 국가 사전(`COUNTRY_RAW`: ISO 숫자 → 한국어 이름·ISO 2자리·대륙)은 `data/countries.ko.json`의 초안으로 씁니다. 대륙 분류는 PRD 10.3절 규칙으로 검토합니다.
5. 시안은 110m 세계 데이터만 넣었습니다. 실제 앱은 PRD 7.2절대로 110m → 50m 교체 로딩을 합니다.
