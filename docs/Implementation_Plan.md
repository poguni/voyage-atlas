## 2. 공통 원칙

1. **빌드 없는 정적 앱**: 브라우저에서 바로 실행되는 ES 모듈입니다. 라이브러리는 import map으로 CDN 버전을 고정합니다. 단, `tools/`의 데이터 전처리 스크립트는 개발할 때만 Node로 한 번 실행합니다.
2. **로컬 실행**: ES 모듈은 `file://`로 열면 동작하지 않으므로 `npx serve .` 또는 `python -m http.server`로 띄웁니다. 실행 방법은 `docs/README_dev.md`에 적습니다.
3. **시안 코드 재사용**: `drawWorld`, `scratch`, `particles`, `countTo`, `toast`, `coin`, `addStar`, 그리고 시안의 CSS 2~3절을 출발점으로 씁니다.
4. **계산은 순수 함수 + 테스트**: 통계·방문 횟수·날짜 합집합은 `js/stats.js`의 순수 함수로 만들고 Node 내장 테스트 러너(`node --test`)로 검증합니다.
5. **화면 확인**: 각 Phase가 끝나면 Playwright로 데스크톱(1440px)과 모바일(390px) 화면을 찍어 시안과 비교합니다.
6. **범위 지키기**: 각 Phase에는 그 Phase의 기능만 넣습니다. 시안에는 있지만 다음 Phase 기능인 요소(예: M1의 AI 탭)는 탭 자리만 두고 "준비 중" 상태로 둡니다.

**확인**: 병합·합의·좌표 검증은 저장된 응답 샘플로 단위 테스트합니다(실제 호출 없이). 실제 호출은 사용자가 키를 넣은 뒤 1회 시험합니다(비용 발생, 사전 안내).

## 12. 커밋 가이드 (사용자 직접 작업)

### 12.1 처음 한 번
```bash
git init
git add docs design .gitignore
git commit -m "docs: PRD v0.3, 디자인 가이드, 구현 계획서 추가"
git branch -M main
git remote add origin <저장소 주소>
git push -u origin main
```
> `.gitignore`는 Phase 0-8에서 만듭니다. 그 전에 첫 커밋을 한다면 `.omc/` 폴더(도구 상태 파일)가 함께 올라가지 않도록 `docs`와 `design`만 지정해 추가하세요.

### 12.2 커밋 시점 원칙
- 각 Phase 표의 "추천 커밋" 시점, 즉 **확인이 끝나 앱이 정상 동작하는 상태**에서 커밋합니다.
- 제가 작업 묶음을 끝낼 때마다 "지금 커밋하기 좋은 시점입니다"와 함께 메시지와 `git add` 대상을 알려 드립니다.
- 데이터 파일(`data/`, `assets/flags/`)은 코드와 분리해 `data:` 커밋으로 올리면 이력이 깔끔합니다.

### 12.3 메시지 형식
`<종류>(<범위>): <한국어 요약>`

| 종류 | 쓰임 |
|---|---|
| `feat` | 새 기능 |
| `fix` | 버그 수정 |
| `data` | 지도·국가·도시·국기 데이터 |
| `docs` | 문서(PRD, 계획서, 안내) |
| `style` | 화면 스타일만 수정 |
| `refactor` | 동작 변화 없는 구조 정리 |
| `test` | 테스트 추가·수정 |
| `chore` | 설정, 도구, 배포 |

### 12.4 GitHub Pages 배포
Phase 1이 끝나면 저장소 Settings → Pages → Branch `main` / `/(root)`로 설정합니다. 앱이 루트의 `index.html`에서 실행되므로 별도 빌드가 필요 없습니다.

## 13. 위험 요소와 대응 (구현 관점)

| 위험 | 대응 |
|---|---|
| 독도가 단순화 과정에서 사라짐 | `keep-shapes` 옵션 + 데이터 테스트로 독도 폴리곤 존재를 매번 검사 + 마커·라벨 항상 표시 |
| 국기가 글자로 보임 | 이모지를 아예 쓰지 않음. 모든 국기는 `flagImg()` 한 함수로만 표시하고, 코드 검사로 지역 표시 문자(U+1F1E6~1F1FF) 사용이 없는지 확인 |
| 도시 데이터 용량 | 필요한 필드만 남기고 짧은 키 사용, 검색을 처음 쓸 때 지연 로딩, 서비스 워커 캐시 |
| 도시 한국어 이름 누락·어색함 | GeoNames 한국어 이름 + 수작업 보강표, 검색은 영어 이름으로도 가능 |
| 시안과 실제 데이터 차이(110m → 50m, 한국 코드 체계) | 시안 코드 이전 시 국가·시도 키를 새 사전 기준으로 바꾸고, 화면 캡처로 비교 |
| 50m 지도 성능 | 110m 먼저 표시 후 교체, 확대·이동 중 무거운 필터 끄기 |
| AI 모델 이름·사양 변경 | 4-0에서 확인, 슬러그는 설정값 |
| 공유 이미지 한글·국기 깨짐 | Canvas `fillText`, 국기 SVG를 이미지로 불러 그림, 기기별 확인 |
