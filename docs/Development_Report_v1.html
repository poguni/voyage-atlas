2. 목표 및 배경

여행은 다녀온 뒤에 기억이 흩어지기 쉽습니다. 언제 어디를 몇 번 갔는지는 금방 헷갈리고, "언젠가 가고 싶은 곳"은 머릿속에만 머물다 잊힙니다.

종이 스크래치 맵은 금박을 긁는 단순한 행동만으로 큰 성취감을 줍니다. 이 앱은 그 감각을 디지털로 옮기고, 종이 지도로는 할 수 없는 세 가지를 더합니다.

  1. 기록: 방문 날짜·횟수·동행·메모를 쌓아 "나의 여행 연대기"를 만듭니다.
  2. 통계와 성취: 방문 국가 수, 대륙 비율, 여행 일수, 이동 거리, 배지로 성장을 보여 줍니다.
  3. 희망: 위시리스트와 AI 추천 여행지를 지도 위에 별처럼 띄웁니다.

디자인이 전달해야 할 감정은 성취감(긁기·배지), 추억(연대기·경로 다시 보기), 기대(별·D-day), 자부심(포스터 품질 공유 이미지) 네 가지로 정했습니다. 디자인 콘셉트는 "Midnight Atlas & Gold Foil"(밤하늘 + 금박)입니다.

성공 지표(개인 사용 기준): 첫날 10분 안에 다녀온 곳 모두 색칠, 귀국 1주일 안에 기록 90% 이상, 공유 이미지 1회 이상 공유, 위시 1곳 이상 "꿈 → 현실" 전환, AI 추천지 1곳 이상을 트립픽 후보로 검토.

3. 주요 기능

지도

  • 세계(Natural Earth 투영) · 2D 지구본(자전·관성) · 대한민국(시도 17칸 / 시군구 230곳) 보기와 투영 전환 연출
  • 클릭 팝오버 → 금박 긁기 연출(850ms 마스크 + 금가루), 빠른 색칠 모드, 5초 실행 취소
  • 상태: 방문함 / 경유(빗금) / 위시(점선 + 별) / 미방문. 방문 횟수 4단계 오로라 색
  • 색칠 기준 전환: 방문 횟수 · 상태 · 마지막 방문 연도 · 동행 유형
  • 작은 나라 원형 마커 43개, 독도 마커·라벨 항상 표시, 다녀온 도시 핀
  • 한국어·영어·초성 검색(나라·시도·도시 3만 3천 곳)
  • 3D 시네마틱 지구본(globe.gl 지연 로딩): 솟아오른 나라, 금빛 비행 궤적, 여정 투어

기록·통계

  • 여행 연대기(연도별 타임라인), 경로 지도(대권 곡선), 경로 다시 보기(비행기 아이콘), 전체 연대기 재생(연도 슬라이더), 다가오는 여정 D-day
  • 장소 상세(국기, 방문 기록, 관련 여행, 도시 칩, 메모, 대표 사진)
  • 통계 대시보드: KPI 4칸(방문국·대륙·여행 일수·지구 ○바퀴), 대륙 도넛, 연도별·월별 막대, 많이 간 나라 TOP 5, 동행 비율, 위시 달성률, "기록으로 본 나"
  • 마일스톤 배지 13개, 축하 창(코인 회전 + 색종이), 배지 보관함, 다음 목표 제안

위시·AI

  • 위시리스트(우선순위·목표 시기·D-day·예산·링크), 끌어서 순서 변경, "다녀왔어요" → 별이 떨어져 색칠되는 연출
  • AI 추천: OpenRouter로 Claude Sonnet 5.5 · GPT-6 Luna · Gemini 3.8 Flash 병렬 호출 → 결과 병합·합의(3/3·2/3·1/3) → 지도 핀, 비용 확인 창(USD·원화), 캐시, 지난 추천, 웹 검색 토글

공유·데이터

  • 공유 스튜디오: 템플릿 5종(월드 포스터 · 대한민국 정복 지도 · 올해의 여정 · 여행 카드 · 위시 보드), 크기 5종(인스타 세로·스토리·정사각·가로·인쇄 A3), 테마 3종, PNG 저장·Web Share
  • IndexedDB 자동 저장, JSON 백업·복원(덮어쓰기/합치기, 사진 포함 선택), 백업 권유 배너, CSV 내보내기·이름 목록 붙여 넣기 색칠
  • PWA 오프라인 캐시(약 380개 파일), 효과음(Web Audio), 다크·라이트 테마, 애니메이션 줄이기
  • 트립픽 연동 JSON과 '추천 제외 조건' 문장 복사

6. 주요 의사결정과 이유

결정대안이유
빌드 없는 다중 파일 정적 앱(B안)A. 단일 HTML / C. Vite + TS + React + MapLibre단일 HTML은 4,000줄을 넘으면 관리가 어렵고, C안은 빌드 부담이 크고 긁기 연출·공유 이미지가 오히려 복잡해짐. 3D만 P2에서 부분 도입
국기는 SVG 이미지, 이모지 금지국기 이모지윈도우에서는 국기 이모지가 "KR" 같은 글자로 보임. 테스트로 코드에 국기 이모지(U+1F1E6~1F1FF)가 없는지 매번 검사
지도 데이터는 저장소에 보관CDN에서 불러오기외부 변경·장애에 흔들리지 않고 오프라인 캐시가 쉬움
한국 17칸 유지2026-07 통합된 전남광주통합특별시를 1칸으로여행 기록은 광주와 전남을 따로 기억하는 경우가 많음. 툴팁에 행정 명칭을 함께 표시
독도 원본 폴리곤 다시 넣기단순화 결과 그대로단순화하면 독도가 사라짐. 동도·서도 원본을 다시 넣고 테스트로 좌표 포함 여부 검사
'거주' 상태 삭제, 대한민국도 방문국거주 상태 유지상태를 단순하게. 한국 시도를 하나라도 방문하면 대한민국 자동 방문
방문 횟수 = 여행 수(단순 표시는 흡수)표시 + 여행 합산표시만 하다가 여행을 넣었을 때 횟수가 부풀지 않게
미래 날짜 여행은 통계 제외포함"다가오는 여정"으로 따로 보여 주고 D-day에 사용
공유 이미지를 Canvas에 직접 그리기오프스크린 SVG → 이미지 변환SVG → 이미지 변환 때 글꼴이 빠지는 문제가 아예 생기지 않음
AI 글자는 모두 이스케이프marked + DOMPurify마크다운을 쓰지 않으므로 라이브러리가 필요 없음. XSS 위험도 원천 차단
**AI 결과 좌표를 d3.geoContains로 검증**그대로 믿기모델이 바다나 다른 나라 좌표를 줄 때 "위치 확인 필요"로 표시하고 보정
앱 코드는 네트워크 먼저, 데이터는 캐시 먼저전부 캐시 먼저배포한 뒤 캐시 이름을 안 바꿔도 다음 실행에 최신 코드가 적용됨
2D 지구본은 110m 지도50m매 프레임 다시 그려서 50m는 휴대폰에서 무거움
3D는 전체 화면 별도 보기지도의 네 번째 보기검색·색칠 같은 2D 기능과 섞지 않음. 닫을 때 WebGL 자원 정리

8. 보안/성능 고려사항

보안·개인정보

  • 서버가 없고 기록은 모두 이 기기(IndexedDB)에만 저장합니다.
  • OpenRouter API 키는 "이 기기 저장 / 이번 세션만" 중에서 고르고, JSON 백업에 넣지 않습니다.
  • AI에 보내는 이력 요약에는 메모·여행 제목·동행인 이름을 넣지 않습니다(테스트로 확인).
  • AI 응답은 모두 이스케이프해서 표시합니다.
  • AI 실행 전 예상 비용을 보여 주고, 실행 후 usage.cost로 실제 비용을 기록합니다.

성능

  • 세계 지도는 110m(104KB)를 먼저 그리고 50m(725KB)로 바꿉니다.
  • 시군구 경계·도시 데이터·globe.gl은 처음 필요할 때만 불러옵니다.
  • 공유 이미지 그리기 + PNG 변환은 0.1~0.25초입니다.
  • 통계 계산 목표: 여행 500개에서 50ms 이내.
  • 애니메이션 줄이기 설정이면 긁기·회전·색종이·카메라 이동을 생략합니다.

11. 알려진 한계

  • 기기 간 동기화 없음: 다른 기기로 옮기려면 JSON 백업을 직접 옮겨야 합니다.
  • 3D 지구본 첫 표시가 느릴 수 있음: 그래픽 가속이 없는 시험 브라우저에서 약 14초. 실기기 확인이 필요합니다. 덜 자세한 지도를 쓰면 빨라지지만 제주도가 빠집니다.
  • 트립픽에 가져오기 기능이 아직 없음: 지금은 제외 조건 문장을 복사해 붙여 넣는 방식만 바로 쓸 수 있습니다.
  • 실기기 확인 남음: 사파리(iOS)·삼성 인터넷의 공유 창과 한글 글꼴, 실제 API 키로 AI 1회 실행(약 $0.03).
  • 저장 지연: 마지막 변경 0.15초 안에 새로 고침하면 그 변경이 빠질 수 있습니다.
  • 작은 마을 누락: 인구 1천 미만 마을(할슈타트 등)은 도시 데이터에 없습니다.
  • 오프라인 글꼴: 한글 글꼴은 화면에 나온 글자 조각만 캐시해서, 오프라인에서 처음 보는 글자는 기본 글꼴로 보일 수 있습니다. 3D는 온라인일 때 한 번 열어 두어야 오프라인에서 열립니다.
  • 위시 자유 장소: 지도에서 위치를 직접 찍지 못하고, 가까운 도시·나라 + 표시 이름 방식입니다.
  • 휴대폰 지도 화면의 3단계 하단 시트 미적용(패널만 하단 시트).
  • 빠른 색칠 + 두 번 누르기: 시도를 두 번 누르면 색칠이 켜졌다 꺼진 뒤 시군구로 바뀝니다(위쪽 전환 버튼 권장).
  • 대표 사진은 장소마다 1장, 여행별 사진은 없습니다.

12. 향후 개선 아이디어 / 업데이트 계획

다음에 하면 좋을 것 (Phase 6 남은 것과 미룬 것)

  1. AI 여행 성향 분석(F7-11): 기록을 바탕으로 "자연·도시·미식" 같은 성향 카드. 이미 만든 이력 요약(메모 제외)을 재사용할 수 있습니다.
  2. 재미 배지(F5-5): 남반구, 적도 넘기, 섬 수집가, 10년의 여정(시안에 디자인 있음).
  3. 인쇄용 SVG/PDF(F8-11): A3 PNG에 더해 벡터 출력.
  4. 시군구 정복률(F4-4 P1): 5d·5e에서 두 번 미룸. 한국 HUD에 "시군구 n/230".
  5. 3D 지구본 실기기 성능 확인: 느리면 처음엔 110m로 그리고 뒤에서 50m로 바꾸는 방식(2D 지도와 같은 전략)을 검토.

여유가 있으면

  • 트립픽 쪽 가져오기 기능: 지금 만든 JSON({ name, country, region, code, note })을 그대로 읽게 하면 위시 → 트립픽 후보가 한 번에 넘어갑니다.
  • 저장 지연 보완: pagehide/visibilitychange 때 바로 저장해서 0.15초 사이 새로 고침 손실을 막기.
  • 위시 자유 장소의 위치 찍기: 지도를 눌러 좌표를 정하는 모드.
  • 휴대폰 3단계 하단 시트: 지도를 크게 보면서 HUD를 끌어올리는 방식(DESIGN 5.4).
  • 여행 카드 날짜 표시: 앞서 미뤄 둔 항목.
  • E2E 테스트 자동화: 지금은 Phase마다 Playwright로 손으로 확인합니다. 시나리오 B 같은 핵심 흐름을 스크립트로 남기면 회귀를 잡기 쉽습니다.
